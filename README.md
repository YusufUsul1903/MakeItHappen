# MakeItHappen

## Introduction

MakeItHappen is een to-do applicatie waarmee gebruikers hun taken kunnen beheren. 
Gebruikers kunnen zich registreren en aanmelden, waarna ze hun eigen taken en categorieën kunnen beheren.

De applicatie is gebouwd met Node.js en Express en maakt gebruik van EJS voor de views. 
Voor de opslag van gegevens wordt SQLite gebruikt in combinatie met Knex en Objection.

Authenticatie gebeurt via JWT en wachtwoorden worden veilig gehasht met bcrypt.
